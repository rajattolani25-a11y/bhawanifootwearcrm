# Category-aware Kinetic Spotlight

The owner approved option 03 and the smaller, category-aware follow-up preview. This updates the existing Spotlight, not the catalog hero or a second carousel. Prices, inventory, checkout, payment and product-opening actions continue using the existing catalog data and handlers. No SQL, storage uploads, video or animation runtime is needed.

`spotlightStyle` maps only saved categories through the existing taxonomy parser. Sports, streetwear, formals, heels, flats, sandals, slippers and children have distinct words/palettes; adult legacy aliases remain supported. Other/custom/missing categories use neutral EXPLORE. In All, the actual centered pair determines the heading and palette. Existing department, style, size and search filters supply all eligible pairs; no unrelated category is substituted. An enabled Spotlight now also shows a single matching pair, with no navigation or autoplay. Zero matches hide it.

The photo is 86% of its slide (previously 94%), contained without cropping. Center artwork is sharp, neighboring photos use a static small blur, and movement uses transform/opacity with a 750 ms easing curve. The retained outgoing photograph survives 800 ms at shuffled boundaries. Actual color properties interpolate over 650 ms; unregistered custom properties/gradients are not relied on for smooth blending. At most three photographs mount and the old frame remains until the requested image decodes. No per-frame JavaScript, real 3D, or new network services are added.

Existing three-second autoplay, random visit/cycle order, arrows/swipe, exact product links and hover/focus/touch/offscreen/hidden-tab pause behavior remain. Owner gallery OFF hides the section; category accents OFF uses the saved catalog palette, while the correct category heading remains. Owner motion OFF/reduced motion remove autoplay/transitions. Dark styles are scoped to this section. Other catalog theme/layout and financial data are unchanged.

Validation: `tests/catalog-spotlight-category-browser-audit.mjs` covers the 15 saved/legacy/custom category cases, All membership, single-result filtering, exact product opening, retained image nodes, actual background-color interpolation, 320/390/768/1440 layouts, dark/owner controls and zero external requests/writes. The existing Spotlight audit covers shuffle/autoplay/pause/blocked-storage behavior. Desktop/mobile local browser checks do not guarantee a particular customer's device frame rate.
