# Hero fonts

Self-hosted Latin WOFF2 files, scoped to CatalogHero. No runtime package dependency or external font request is introduced. Other scripts fall back to the existing font stack.

- @fontsource/barlow-condensed 5.3.0, SIL Open Font License 1.1. Original font files; license text included alongside. https://www.npmjs.com/package/@fontsource/barlow-condensed
- @fontsource-variable/bodoni-moda 5.3.0, SIL Open Font License 1.1. Original font files; license text included alongside. https://www.npmjs.com/package/@fontsource-variable/bodoni-moda
